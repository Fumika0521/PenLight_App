# Light Deco ♡ - 推しペンライトデコアプリ

推しのペンライトを自分好みに可愛くデコレーションできるWeb＆スマートフォン向けアプリ「**Light Deco（ライトデコ）**」です。

パステルピンクやブルーを基調とした「夢かわいい」世界観で、リボン、ラインストーン、文字、写真パーツを自由に配置・カスタマイズし、世界にひとつだけのオリジナルペンライトを作成・保存・共有できます。

---

## 🌟 主な機能と特徴

### 1. 2つの体験モード（切り替え可能）
- **💻 Web試作品（PC・タブレット向け）**:
  - 左側にナビゲーション＆パーツ選択メニュー
  - 中央に大画面キャンバス（ドラッグ移動、拡大・縮小、回転、重なり順調整、アンドゥ/リドゥ、ズーム機能）
  - 右側に詳細カスタマイズパネル（スライダー、位置微調整十字キー、カラーパレット）
  - 右端に常時連動するリアルタイムプレビュー＆ワンクリック画像保存
- **📱 スマホアプリ版（画面フロー体験）**:
  - ホーム画面（完成イメージの展示、「新しくデコる」ボタン）
  - ペンライトベース選択画面（4タイプ）
  - 編集画面（下部ドック、人気パーツのクイック配置バー）
  - パーツ一覧モーダルシート
  - カラー変更画面（発光カラー、カバー色、透明度、発光アニメーション）
  - 完成画面（紙吹雪演出、オリジナル署名「My Lightstick ♡」）

### 2. 4種類のペンライトベース
- **定番タイプ**: 王道の球体ドーム型ペンライト（ドーム内に推しの写真を入れることも可能）
- **ハートタイプ**: ガーリーで愛らしい3Dクリスタルハート型
- **スタータイプ**: キラめく星型のペンライト
- **ダイヤタイプ**: 気品と輝きを放つクリスタルダイヤモンド型

### 3. 豊富なデコレーションパーツ
- **リボン**: サテンリボン、ツインリボン、レースリボン、ビジューリボンなど
- **ハート**: ラインストーンハート、ホログラムハート、天使の羽ハート、パール囲みハートなど
- **星**: パステルスタ―、キラキラスター、瞬き4点スターなど
- **ラインストーン＆パール**: 各色ジュエルストーン、一粒パール、パールアーチ、フラワーパールなど
- **チャーム**: プリンセスクラウン、うさ耳、ねこ耳、オーロラバタフライなど
- **推し文字＆ステッカー**:
  - 定番ワード（`LOVE`, `OSHl`, `推し`, `尊い`, `天使`, `すき♡` など）
  - アルファベット・記号スタンプ
  - 自由なテキスト入力＆カラー選択
- **推し写真**:
  - サンプルアイドルアイコン
  - お使いの端末から自由な推し画像・イラストのアップロード（ステッカー配置またはドーム内配置）

### 4. ライブ演出モード（暗闇モード）
- ステージライトと暗闇演出をONにして、コンサート会場さながらのペンライトの輝きを体感できます。

### 5. 画像保存＆共有
- 高解像度PNG画像としてワンクリックで端末にダウンロード保存
- ブラウザのローカルストレージへのデザイン保存・読み込みギャラリー
- Web Share / URLコピーによるSNS共有

## 🚀 起動方法

### 開発サーバーの起動
```bash
npm run dev
```
ブラウザで `http://localhost:5173` を開いて操作できます。

### プロダクションビルド
```bash
npm run build
npm run preview
```
